# Главный экран SPAR / Простоквашино

Макет: https://www.figma.com/design/konvmvXiM0ACaO4ExAD5Q4/Desktop?node-id=79-381

## Установка в Tilda

1. Добавьте блок «Другое → T123 HTML-код» первым блоком страницы.
2. Скопируйте всё содержимое `tilda-main.html` в поле HTML-кода.
3. Установите внешние отступы блока сверху и снизу в 0.
4. Кнопка ведёт к `#spar-entry` — идентификатору отдельного блока «Форма участия». Установите оба блока на одной странице. Старую внешнюю ссылку на акцию Twix из макета намеренно не используем.
5. Проверьте результат на опубликованной тестовой странице Tilda: редактор может не отображать HTML-код полностью.

Страница в Tilda в рамках этого этапа не изменялась и не публиковалась.

## Файлы

- `tilda-main.html` — автономный код блока со встроенными стилями и постоянными ссылками на GitHub.
- `index.html`, `hero.html`, `hero.css` — локальное превью и отдельные исходники.
- `assets/` — все 23 исходных графических файла главного экрана и два шрифта SPAR из существующего репозитория.
- `asset-manifest.json` — соответствие слоёв Figma и CSS-классов.

Макет десктопа перенесён послойно, без использования скриншота вместо интерфейса. На мобильных экранах текст и кнопка размещены над иллюстрацией. Стили ограничены `#spar-hero`, сторонние библиотеки и JavaScript не нужны. Для даты использован шрифт SPAR Normal: исходный TT Firs Text Trial не был предоставлен.

Проверены ширины 320, 375, 430, 768, 1024, 1440, 1920 и 2560 px: все изображения загружены, горизонтального переполнения нет, заголовок помещается, высота кнопки не менее 48 px. Визуально проверены мобильная, планшетная и десктопная композиции. Поддерживается клавиатурный фокус. Переход к будущей форме проверяется после её установки.

Требуются современные браузеры с поддержкой CSS container query units (cqw). Цвет следующей секции из макета — #0465ae.
