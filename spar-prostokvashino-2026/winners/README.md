## Добавление победителей

В `tilda-winners.html` найдите `<script type="application/json" id="spar-winners-data">`. Именно этот встроенный JSON используется блоком. `winners-data.json` — отдельная копия для редактирования; изменения в ней нужно перенести во встроенный JSON. Данные не загружаются с сервера автоматически.

Каждый розыгрыш имеет id, label и массив winners. В winner используйте строковые поля participantId, name и prize. Сохраняйте номера строками, чтобы не потерять ведущие нули. При вставке JSON в HTML экранируйте символ `<` как `\u003c`.

Пример структуры записи (только пример, в готовом блоке таких записей нет):

```json
{"participantId":"000123","name":"Имя для публикации","prize":"1 000 бонусов"}
```

Поиск фильтрует номер участника в выбранном розыгрыше; поддерживает частичное совпадение. Даты создаются из JSON. Таблица использует безопасный textContent для значений. Пустой розыгрыш показывает «Победителей пока нет», отсутствие совпадений в заполненном розыгрыше — отдельное сообщение. Выдуманных победителей в блоке нет.

## Проверки

Проверены ширины 320–2560 px, переключение даты, поиск существующего и отсутствующего номера на отдельной локальной тестовой странице. Тестовые записи не включены в репозиторий и готовый блок. Кнопки дат не ниже 44 px; есть клавиатурный фокус, семантическая таблица и сообщения для скринридера. Горизонтального переполнения страницы нет.

`index.html` — превью; `winners.html`, `winners.css`, `winners.js` — раздельные исходники; `tilda-winners.html` — автономный код T123.
