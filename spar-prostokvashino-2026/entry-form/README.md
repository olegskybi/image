# Форма участия — демонстрационный блок Tilda

По вашему указанию форма работает без отправки. Она проверяет поля, но не регистрирует участника, не передаёт данные и не сохраняет их в хранилище браузера. Этот режим явно отмечен под кнопкой. После проверки показано сообщение «Заявка не отправлена».

## Установка

1. Добавьте отдельный T123 после блока «Товары-участники».
2. Вставьте всё содержимое `tilda-entry-form.html`, включая CSS и JavaScript.
3. Установите внешние отступы T123 сверху и снизу в 0.
4. Ссылка с главного экрана должна вести на `#spar-entry`. Обновлённый главный блок уже использует этот адрес.

В Tilda блок не устанавливался и страница не публиковалась.

## Поля и ограничения

Сохранены поля макета: фамилия и имя, телефон, e-mail, способ покупки, два согласия. Варианты «В магазине» и «Онлайн-заказ» — предварительные, так как раскрытый список отсутствовал в Figma. Поля чека или номера заказа не добавлялись: их нет в предоставленном экране.

Ссылка на правила сохранена из макета. Ссылка на документ обработки персональных данных не предоставлена: соответствующий текст пока не является ссылкой. Перед реальным запуском нужны обработчик заявок, серверная проверка, согласованный список способов покупки и актуальные документы. Никакого фиктивного успешного ответа нет. Inline-обработчик onsubmit блокирует стандартную отправку формы даже при недоступном основном скрипте.
