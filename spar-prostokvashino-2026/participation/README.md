# Как принять участие — отдельный блок Tilda

1. Добавьте блок «Другое → T123 HTML-код» сразу после главного экрана.
2. Вставьте в него всё содержимое `tilda-participation.html`.
3. Установите внешние отступы T123 сверху и снизу в 0: необходимые отступы уже заданы внутри секции.
4. Проверьте опубликованную тестовую страницу. Секция работает независимо от главного экрана, без JavaScript и библиотек.

Этот этап не изменяет и не публикует страницу в редакторе Tilda.

Файлы: `index.html` — локальное превью, `participation.html` и `participation.css` — раздельные исходники, `tilda-participation.html` — готовый блок с постоянными ссылками GitHub, `assets/` — исходные изображения и шрифты, `asset-manifest.json` — соответствие слоям Figma.

Figma: файл konvmvXiM0ACaO4ExAD5Q4, узлы 79:336 и 79:376. Сохранены SVG-фон карточки, голубой бонусный билет, бутылка молока, сметана и чек. Заголовки используют фирменный SPAR Bold. Для описаний использован Arial Italic: CoFo Hand Trial из макета не предоставлен.

На десктопе — три карточки в ряд; до 768 px — вертикальный список. Проверены ширины 320, 375, 430, 768, 1024, 1440, 1920 и 2560 px: все изображения загружены, заголовки помещаются, горизонтальной прокрутки нет. Текст остаётся текстом, структура шагов — семантический список. Цвет фона #0063b4 взят из Figma.

В макете карточки информационные: дополнительных кнопок, форм и ссылок здесь нет.
