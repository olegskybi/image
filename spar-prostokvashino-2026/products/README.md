# Товары-участники — отдельный блок Tilda T123

1. Добавьте «Другое → T123 HTML-код» после блока «Что можно выиграть».
2. Вставьте всё содержимое `tilda-products.html`, включая style и script.
3. Задайте внешние отступы T123 сверху и снизу 0.
4. Проверьте опубликованную тестовую страницу: редактор Tilda может не исполнять JavaScript блока.

Страница Tilda в рамках этого этапа не изменялась и не публиковалась.

## Содержимое и поведение

Макет Figma konvmvXiM0ACaO4ExAD5Q4, узел 79:190, содержит три одинаковые карточки «Сметана Простоквашино 15%, 300г». Они сохранены без выдумывания ассортимента. Для запуска акции замените их реальным списком товаров при необходимости.

На широком экране видны три карточки, на планшете две, на телефоне одна. Прокрутка работает свайпом, стрелками и клавишами ArrowLeft, ArrowRight, Home, End. Стрелки отключаются на границах; когда видны все три товара, обе неактивны. Без JavaScript остаётся нативная горизонтальная прокрутка. Автопрокрутки нет. Кнопка «Весь ассортимент» ведёт на https://myspar.ru/catalog, как в макете.

`tilda-products.html` — автономный блок со встроенными стилями, логикой и постоянными ссылками GitHub. `index.html` — локальное превью; `products.html`, `products.css`, `products.js` — отдельные исходники. `products.json` — справочный список текущих карточек, не загружается автоматически. Для изменения состава отредактируйте карточки в HTML или пересоберите блок генератором. `asset-manifest.json` связывает изображения со слоями макета.

Изображения и SVG-стрелки — исходные файлы Figma. Шрифты SPAR используются из существующего репозитория. Для веса использован Arial Italic вместо отсутствующего CoFo Hand Trial.

Проверены ширины 320, 375, 430, 768, 1024, 1440, 1920, 2560 px: изображения загружаются, текст помещается, горизонтального переполнения страницы нет. Проверены переходы на вторую и третью карточку, отключение следующей стрелки в конце и возврат клавишей Home. Кнопки стрелок 44×44 px, мобильная кнопка каталога не ниже 52 px. Есть видимый клавиатурный фокус, объявление позиции для скринридера и поддержка prefers-reduced-motion.
