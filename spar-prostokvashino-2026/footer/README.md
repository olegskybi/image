# Футер — условия акции и забор

Вставьте всё содержимое `tilda-footer.html` в отдельный блок T123 после блока «Не нашёл ответа на свой вопрос?». Внешние отступы блока сверху и снизу: 0. Не добавляйте этот же футер дважды на страницу.

Изображение и шрифты загружаются из olegskybi/image, spar-prostokvashino-2026/footer/assets. Локальный просмотр: index.html. CSS изолирован внутри #spar-footer; JavaScript не нужен.

На широком экране сохранена композиция Figma: белый текст по центру, галчонок слева, забор во всю ширину. На планшетах и телефонах текст расположен над декорацией, шрифт увеличен; изображение пропорционально обрезается справа, галчонок остаётся видимым.

По прямому указанию пользователя временно сохранены название «Насладись и выигрывай призы», даты мая–июля 2026, покупка от двух товаров и ссылка из макета. Это не утверждённые условия акции «Поймай волну удачи». Перед запуском заменить утверждённым текстом.
