# Поймай волну удачи — единый сайт для Tilda

1. Добавьте на страницу один HTML-блок T123.
2. Скопируйте в него всё содержимое tilda-site.html.
3. Установите внешние отступы блока сверху и снизу 0. Уберите предыдущие отдельные секции, чтобы не дублировать содержимое и ID.
4. Отключите стандартные шапку/подвал страницы, если они подключены в настройках Tilda. Проверьте опубликованную страницу: редактор Tilda может не выполнять пользовательский JavaScript.

index.html — автономный локальный просмотр со всеми изображениями. site.css и site.js — общие стили и поведение. Изображения в T123 используют уже опубликованные файлы olegskybi/image. Шрифт загружается одной парой файлов для всего сайта. Никаких библиотек и сборщика не требуется.

Все 9 секций идут в согласованном порядке. Кнопка первого экрана ведёт к форме. Товары прокручиваются, FAQ раскрывается, поиск и даты победителей работают; кнопка поддержки открывает письмо на skubev@spar-nn.ru.

Сохранённые ограничения: форма проверяет поля, но не отправляет и не сохраняет заявки; в FAQ «Ответ скоро появится»; список победителей пустой, даты из макета; условия и ссылка на правила старой акции оставлены по указанию пользователя. Перед запуском приёма заявок понадобятся актуальные условия, политика обработки данных, ответы и подключение отправки.
